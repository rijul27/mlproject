About The Project

Turning student data into predictions

This project demonstrates a complete machine learning workflow from raw data to a deployed prediction application.

Problem Statement

The objective is to predict a student's mathematics score using demographic, socioeconomic and academic features such as gender, race/ethnicity, parental education, lunch type, test preparation, reading score and writing score.

Project Approach

The project performs data ingestion, train-test splitting, preprocessing, categorical encoding, numerical scaling, model comparison, hyperparameter tuning and final prediction.

Dataset

Student Performance Dataset

The dataset contains demographic information and academic examination scores for student performance analysis.

Machine Learning Pipeline

From raw data to prediction

01 · Data Ingestion Read the source dataset, save the raw data and create training and testing datasets.
02 · Data Transformation Handle missing values, encode categorical variables and scale numerical features.
03 · Model Training Train multiple regression algorithms, evaluate them and perform hyperparameter tuning.
04 · Prediction Load the saved preprocessing pipeline and model to generate predictions for new students.
