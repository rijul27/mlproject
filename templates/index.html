About The Project

Turning student data into predictions

Student Performance AI demonstrates a complete machine learning workflow from raw data to a deployed prediction application.

Problem Statement

The objective is to predict a student's mathematics score using demographic, socioeconomic and academic features such as gender, race/ethnicity, parental education, lunch type, test preparation, reading score and writing score.

Project Approach

The project performs data ingestion, train-test splitting, preprocessing, categorical encoding, numerical scaling, model comparison, hyperparameter tuning and final prediction.

Machine Learning Pipeline

From raw data to prediction

The application follows a modular end-to-end machine learning architecture.

01 · Data Ingestion Load the dataset, save raw data and split the data into training and testing datasets.
02 · Data Transformation Handle missing values, encode categorical variables and scale numerical features.
03 · Model Training Train multiple regression models, compare R² scores and perform hyperparameter tuning.
04 · Prediction Load the saved preprocessor and trained model to generate predictions for new students.
